What do the controls and numbers mean?
New BrainFresh random network. Save first if you want to keep the current run.
LearnRuns guarded PPO on the autonomous Learner. Earlier skills are continuously rehearsed alongside the current curriculum.
Cognitive FlowAnimates real sensory influence, recurrent memory links, policy/value pathways, decision confidence, reward and novelty. It is a read-only visualization of the actual running networks.
Attention + EchoProjects real input influence into the world as light fields, then overlays the curiosity model’s predicted next sensory state against what actually happened. Gold is predicted; cyan is actual. Visual only.
CuriosityA tiny learned forward model predicts the next sensory state. Unexpected-but-nonterminal transitions add a tightly capped intrinsic bonus during training only. Evaluations never include it.
ObserveStops learning and watches the selected Learner/Champion brain act at human speed.
ProbeFreezes action. Move food/hazard/agent and inspect real policy changes.
ComputeEco reduces heat; Balanced is default; Adaptive changes only idle delay based on browser responsiveness; Max favors throughput. Learning math is unchanged.
View BrainLearner changes continuously. Frozen Champions and Hall-of-Fame brains can be inspected in Observe/Probe without being modified.
Save ManualSaves the current run to the manual slot. Recovery protection refuses to overwrite a manual brain with a lower-step brain.
Load Manual / AutosaveEach stored slot is shown separately with its step count and timestamp. Loading pauses training for verification.
Unseen TestFinal all-skills holdout. Diagnostic only: it never selects archives or triggers rollback. Use sparingly so human decisions do not overfit it.
Compare BrainsReplays historical brains on a separate comparison-only holdout, not the final Unseen Test domain.
Pin ChampionCopies a Champion into the permanent Hall of Fame. The Hall uses its own browser-storage record as well as checkpoint backup.
Fork New LearnerManual experiment only: freezes the active Learner, starts a new lineage from a Champion/Hall brain, and keeps the old lineage available to switch back to.
Switch BranchFreeze the current lineage and resume another stored Learner lineage. Only one branch trains at a time to avoid wasting phone compute.
ReturnRecent average total reward. Higher is better, but reinforcement learning is noisy.
FoodRecent average resources collected per episode.
EntropyPolicy uncertainty/exploration. High means action probabilities are more spread out.
ValueThe critic's estimate of expected future return from the current state.
Validation12 fixed seeds per skill for routine checks. Suspicious drops trigger a larger paired fixed-seed confirmation pass against the exact previous same-lineage checkpoint before MicroMind uses the word CONFIRMED.
Rear-Target AuditRead-only controlled turn test. It places food at fixed bearings around the agent and measures facing, spinning, reaching, angular travel, and BRAKE use without changing the Learner.
