What do the controls and numbers mean?
New BrainFresh random network. Save first if you want to keep the current run.
LearnRuns PPO training. The visible world is only one of several training environments.
ObserveStops learning and watches the selected Latest/Best brain act at human speed.
ProbeFreezes action. Move food/hazard/agent and inspect real policy changes.
ComputeEco reduces heat; Balanced is default; Max favors throughput.
View BrainLatest is actively training. The protected archive separately preserves Balanced, Overall-return, Forager, Survivor, and Efficiency specialists.
Save ManualSaves the current run to the manual slot. Recovery protection refuses to overwrite a manual brain with a lower-step brain.
Load Manual / AutosaveEach stored slot is shown separately with its step count and timestamp. Loading pauses training for verification.
Unseen TestManual generalization test on a separate held-out seed domain.
Compare BrainsReplays historical milestone brains against identical held-out worlds.
Restore SelectedExplicitly restore the selected protected archive brain + optimizer. Experience steps remain monotonic; this never happens automatically.
ReturnRecent average total reward. Higher is better, but reinforcement learning is noisy.
FoodRecent average resources collected per episode.
EntropyPolicy uncertainty/exploration. High means action probabilities are more spread out.
ValueThe critic's estimate of expected future return from the current state.
ValidationA fixed all-skills suite checks every curriculum stage, detects forgetting, updates specialist archives, and creates a local autosave.
