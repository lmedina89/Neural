# Roadmap

Current: **v0.1.2 Autonomous Continual Learning**.

Next candidates, only after physical validation:
1. intrinsic curiosity / novelty reward;
2. learned predictive world model;
3. visualized imagined rollouts;
4. primitive planning;
5. longer-memory tasks and richer partial observability.

Do not increase network size until evidence shows a capacity ceiling rather than a training/continual-learning limitation.
